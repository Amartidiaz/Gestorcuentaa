Conectar con Dropbox

Para activar la sincronización, crea una aplicación en Dropbox Developers, copia su App key y configura esta misma dirección web como Redirect URI. Esta página usa OAuth PKCE; no necesita contraseña ni App secret.

Permisos necesarios: files.content.read y files.content.write. Ruta del archivo: /Cuentas.txt.

Tus configuraciones

Antes de guardar se crea una copia de seguridad en la raíz de Dropbox. Si el archivo cambia en Dropbox desde la última lectura, se cancelará el guardado para evitar sobrescribir cambios ajenos.

Añadir configuración

El panel no almacena tus credenciales en un servidor. Mantén tu móvil protegido y no compartas esta página con terceros.
